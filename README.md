# どこで追いつく？（doko-oitsuku）

先を行く動物に、どこで追いつくかを当てる1日5問のゲーム。先のきょりと速さの倍率から、追いつく地点を4つから選ぶ。正解すると、100 ＋ 10 ＋ 1 ＋ … と棒が積み上がる図が出て、差がはじめて決まった長さより小さくなるのは何回目かも当てる。

遊ぶ: <https://satou-aaaaa.github.io/doko-oitsuku/>

- 話のもとは、ゼノンの「アキレスと亀」。出典は Stanford Encyclopedia of Philosophy「Zeno's Paradoxes」（N. Huggett） <https://plato.stanford.edu/entries/paradox-zeno/> と、アリストテレス『自然学』第6巻（Hardie・Gaye 英訳） <http://classics.mit.edu/Aristotle/physics.6.vi.html> 。
- 等比級数の和 d ＋ d/r ＋ d/r² ＋ … ＝ d×r/(r−1) は計算で確かめています。ゼノンの問いがこれで全部解けたと言えるかは、考え方が分かれます。
- 人と動物は架空で、速さの倍率は計算のための数です。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
